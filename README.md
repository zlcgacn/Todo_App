# 拾序 · Todo App

使用原生 HTML、CSS、JavaScript 和 Local Storage 的中文待办应用。无需安装依赖、无需后端。

## 打开应用

直接双击 `index.html`，使用 Chrome、Edge 或 Firefox 打开。

如果需要通过本地服务器访问，在本目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8000 。按 `Ctrl+C` 停止服务器。

## 功能

- 输入任务后按 Enter 或点击“添加任务”；限制 200 字，拒绝空白内容。
- 点击复选框或任务文字，在完成与未完成之间切换。
- 点击任务右侧的垃圾桶按钮删除任务。
- 查看全部、待完成或已完成任务，以及数量和完成进度。
- 每次操作自动保存，刷新或重新打开同一地址后恢复任务。
- 适配手机和桌面，支持键盘操作与读屏标签。

## 数据保存

任务保存在当前浏览器的 Local Storage，键为 `shixu.todos.v1`。没有服务器，不会上传任务，也不会在不同浏览器或设备之间同步。清除浏览器站点数据会删除任务；隐私模式下的数据可能在关闭窗口后清除。

请使用固定的打开方式：直接打开文件和通过服务器访问的存储相互独立；不同端口也是不同存储。部分浏览器可能限制直接打开文件时的本地存储，此时请使用本地服务器方式。

应用会提示读取或保存异常；读取到损坏数据时暂停修改，避免覆盖原数据。存储空间不足时保留操作前的状态和输入内容。同一地址的多个标签页可同步存储更新，但不提供多人或并发编辑合并。

## 文件

- `index.html`：页面结构。
- `styles.css`：页面样式与响应式布局。
- `app.js`：任务交互、筛选和数据保存。
